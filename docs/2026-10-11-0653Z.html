Anza CEO Proposes Raising Solana Block Compute Limit to 100M CU at 200ms Slots

10 Oct 2026

Anza CEO Brennan Watt opened a GitHub discussion on October 10, 2026 proposing to raise Solana’s per-block compute limit from the current 50M CUs back to 100M CUs, now that 200ms slot times are fully live via SIMD-0525. The rationale is that halving the slot time also halved effective throughput, and restoring 100M CU blocks would recover capacity without slowing the network. No formal SIMD pull request had been filed at the time of reporting, and no activation date was stated. If adopted, the change would double the computational work validators process per unit time, potentially requiring hardware upgrades from some operators. Not investment advice.
