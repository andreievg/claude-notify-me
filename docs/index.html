Alpenglow T−1: Activation Now Possibly 13:20 UTC on 21 Oct; Validators Need Agave 4.3.0; Brief Pause Warned

19–20 Oct 2026

Solana’s Alpenglow upgrade — the largest mainnet consensus change in the network’s history, replacing TowerBFT with Votor — is confirmed for 21 October 2026. Anza originally targeted epoch 1064 at ~14:50 UTC; QuickNode’s updated maintenance notice indicates the activation could move earlier, to approximately 13:20 UTC. Validators must run an Agave client built on version 4.3.0 (not 4.1 as reported in some earlier sources). QuickNode warns users to expect a brief transaction processing pause and possible data-stream interruptions during the handoff. Because consensus votes will move off-chain after activation, officially reported TPS could appear to drop by ~60% — actual user transaction throughput is unaffected. Finality target remains ~150ms (vs. ~12.8s currently); Rotor (Turbine replacement) is planned for a later phase. Not investment advice.
